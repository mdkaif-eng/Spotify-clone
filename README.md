 # 🎵 Spotify Clone (HTML & CSS)

A simple **Spotify Clone UI** built using **HTML5 and CSS3**.  
This project is focused on recreating the frontend design of Spotify for learning and practice purposes.

## 🚀 Features
- Spotify-inspired UI
- Sidebar navigation (Home, Search, Library)
- Music cards layout
- Clean and modern design
- Responsive layout (basic)

## 🛠️ Technologies Used
- HTML5
- CSS3
